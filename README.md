# Koplink Inventory
*[Read in Bahasa Indonesia](#versi-indonesia)*

Koplink Inventory is a web-based application designed to manage product inventory and record daily transactions. Built using the Laravel framework and MySQL database, this system helps streamline stock tracking and reporting.

The primary focus of this system is to simplify the recording of incoming and outgoing goods, as well as providing structured stock reports to monitor item availability effortlessly.

## Key Features
- Product and category management
- Stock transaction recording (incoming and outgoing)
- Automated stock movement history reporting
- Statistical dashboard for monitoring data
- Admin authentication system

## Technology Stack
**Backend & Database:**
- Laravel (PHP Framework)
- MySQL

**Frontend & Interaction:**
- Tailwind CSS
- Blade Templating (HTML)
- JavaScript

## Local Installation
To run this project locally, follow these steps:

1. Clone this repository: `git clone https://github.com/Attarreyzi/Koplink-Inventory.git`
2. Open terminal and run: `composer install`
3. Duplicate `.env.example` to `.env` and configure your database settings.
4. Run application key generation: `php artisan key:generate`
5. Run database migration: `php artisan migrate`
6. Start local development server: `php artisan serve`

## Instalasi Lokal
Untuk menjalankan proyek ini di perangkat lokal, ikuti langkah-langkah berikut:

1. Salin (clone) repositori ini: `git clone https://github.com/Attarreyzi/Koplink-Inventory.git`
